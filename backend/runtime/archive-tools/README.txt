7-Zip Extra 26.06 x64 by Igor Pavlov (unmodified standalone 7za.exe).
Official project and source: https://www.7-zip.org/ and https://www.7-zip.org/download.html
License and redistribution terms: License.txt in this directory.
The app uses this bundled reader to list .7z entries and stream selected pop.bin
contents into memory. Entry paths are not extracted to disk. No separate 7-Zip
installation is needed. The runtime verifies the binary hash before use.
Exact source archive: third-party/7zip/7z2606-src.tar.xz in the app source package.
Official release: https://github.com/ip7z/7zip/releases/tag/26.06
